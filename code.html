Research Projects

alabi

Active Learning Accelerated Bayesian Inference (ALABI) — An open-source Python package for performing Bayesian inference with computationally expensive forward models using Gaussian processes and active learning.

Python Bayesian Inference Gaussian Processes MCMC Active Learning

spotgp

Physically motivated Gaussian Process kernels for modeling stellar starspot variability, implemented in JAX.

Python JAX Gaussian Processes Stellar Variability

vplanet_inference

Python tools for doing statistical inference and model sensitivity analysis with VPLanet, a framework for simulating planetary system evolution.

Python VPLanet Planetary Evolution Bayesian Inference

apogee_tools

Modeling tools for SDSS/APOGEE spectra. Provides utilities for downloading, processing, and fitting stellar spectra from the Apache Point Observatory Galactic Evolution Experiment (APOGEE).

Python APOGEE Spectroscopy Stellar Models
